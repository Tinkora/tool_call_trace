# Support

[简体中文](SUPPORT.zh-CN.md)

Tool Call Trace is currently pre-release. Public support channels are not open
until the repository's moderation prerequisites are verified.

## Self-service

- [README](README.md): supported formats, limits, and local setup.
- [Product specification](docs/PRODUCT_SPEC.md): current scope and non-goals.
- [Maturity evidence](docs/MATURITY.md): publication and stability status.
- [Security policy](SECURITY.md): private vulnerability reporting.

## Once public channels open

- Use Issues for reproducible bugs and evidence-backed feature proposals.
- Use Discussions for usage questions and workflow examples.
- Search existing threads before posting.
- Replace real logs with minimized synthetic traces and remove credentials,
  personal data, proprietary paths, and customer content.

There is no guaranteed response time or commercial support agreement. Never use
a public support channel for a suspected vulnerability.

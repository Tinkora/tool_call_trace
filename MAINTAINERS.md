# Maintainers

Tool Call Trace is currently maintained by:

- [@tinkeragora](https://github.com/tinkeragora)

Maintainers are responsible for release authorization, security response,
repository settings, dependency updates, and final review of changes to parser,
WASM, workflow, and privacy boundaries.

This list records current responsibility rather than permanent ownership. A
future maintainer must demonstrate sustained contributions and accept the
governance and security duties before being added.
